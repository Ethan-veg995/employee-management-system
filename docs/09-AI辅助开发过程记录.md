### 1.2 设计阶段
```
提示词：基于案例需求设计企业员工管理系统的技术方案——
技术栈 Vue3+FastAPI+SQLite；数据库 9 张表；4 角色 JWT 权限；
看板 6 类 ECharts 图表；考勤规则+月度统计口径；请假审批流。
```
产出：架构设计、数据库设计、API 接口设计、Spec。

### 1.3 开发阶段（代表性提示词）
