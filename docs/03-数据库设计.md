# 企业员工管理系统 — 数据库设计

| 文档版本 | V2.0（新增审批/通知/绩效/公告 4 表） |
| --- | --- |
| 数据库 | SQLite（文件：`backend/data/ems.db`） |
| ORM | SQLAlchemy 2.0 |

## 1. ER 关系总览

```
users(用户) ──── N:1 ──── employees(员工) ──── N:1 ──── departments(部门)
                                │
                                └──── N:1 ──── positions(职位)
员工 1:N 审批申请 approval_requests（审批人 = users.approver_id）
员工 1:N 考勤记录 attendance_records
员工 1:N 绩效 performance_reviews（评分人 = users.reviewer_id）
员工 1:N 薪资 salaries
用户 1:N 消息通知 notifications
考勤规则 attendance_rules（单行配置表）
公告 announcements（发布人 = users.publisher_id）
```

## 3. 索引与约束设计

- `employees.employee_no` 唯一索引（工号防重）
- `attendance_records(employee_id, date)` 联合唯一（每人每天一条）
- `salaries(employee_id, year, month)` 联合唯一（每人每月一条）
- `performance_reviews(employee_id, year, month)` 联合唯一（每人每月一条）
- `notifications.user_id` 高频查询（未读统计），数据量小未额外建索引

## 4. 数据口径说明

- 请假/出差天数按**自然日**计算（end - start + 1），简化处理不含周末过滤
- 出勤率口径：实际出勤 ÷ (工作日 - 已通过请假天数)
- 绩效等级映射：S≥90 / A≥80 / B≥70 / C<70；绩效系数 1.5/1.2/1.0/0.6；建议绩效奖金 = 系数 × 基本工资 × 20%（规则集中在 config.py）
- 月度统计中的"离职"计为累计离职人数
- 演示数据由 `seed.py` 生成：5 个部门、14 个职位、16 名员工、4 个演示账号、近 3 个月考勤、6 个月薪资、12 条审批申请（含待审批 2 条）、本月全员绩效、3 条公告、预置通知（未读红点演示）
