# 企业员工管理系统 — 操作手册

| 文档版本 | V2.0 |
| 更新日期 | 2026-08-24 |

## 1. 环境要求

| 软件 | 版本 |
| --- | --- |
| Python | 3.10+（开发环境 3.11） |
| Node.js | 18+（开发环境 24） |

## 2. 本地启动（两步）

### 第 1 步：启动后端（端口 8000）

```bash
cd backend
pip install -r requirements.txt   # 首次运行需安装依赖
python -m app.seed                # 初始化演示数据（首次运行，之后也可随时重跑恢复数据）
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即成功。Swagger 接口文档：`http://127.0.0.1:8000/docs`

### 第 2 步：启动前端（端口 3000）

```bash
cd frontend
npm install    # 首次运行需安装依赖
npm run dev
```

浏览器打开 `http://localhost:3000` 即可使用。

## 4. 功能使用说明

### 4.1 登录
访问首页，点击下方"演示账号"按钮快速填入账号密码，点击"登录"。

### 4.2 数据看板（hr）
登录 HR 账号后默认进入看板：顶部 4 张统计卡片，下方 4 个图表（部门分布、职级比例、请假统计、薪资趋势），底部为智能考勤异常提醒列表。

### 4.3 部门 / 职位 / 员工管理（hr）
左侧菜单进入，右上角"新增"按钮；员工页支持关键词/部门/状态筛选、Excel 导入导出（导入需先下载导出文件作为模板，或按表头：工号、姓名、性别、手机号、邮箱、部门、职位、入职日期、状态）。

### 4.4 考勤打卡（employee/manager）
"考勤打卡"页：上班点蓝色按钮、下班点绿色按钮；下方为当月记录。考勤规则（hr）可配置上下班时间与迟到容忍分钟。

### 4.5 审批工作流（employee/manager）
"发起申请"页：切换请假/加班/报销/出差类型，表单自动变化（请假选类型+日期、报销填金额），填写标题事由提交。主管在"待我审批"通过或驳回（可填意见）。"我的申请"查看历史与状态；顶栏铃铛实时收到待办与审批结果通知。

### 4.6 消息通知
顶栏铃铛显示未读红点（每 30 秒自动刷新），点开查看最近 10 条，可单条点击（待办跳审批页、公告跳公告页）、全部已读。"消息中心"页查看全部历史消息。

### 4.7 绩效管理（manager 给本部门评分 / HR 管理）
"绩效管理"页按月查看；点"绩效评分"选员工打分（0-100），等级 S/A/B/C 自动映射，弹窗内实时显示建议绩效奖金（联动薪资）。HR 可编辑/删除。员工在"我的绩效"查看本人等级与历史。

### 4.8 公告中心（全员）
HR 发布/编辑/删除公告，发布自动通知全员；员工在公告页或工作台查看最新公告。

### 4.9 薪资（hr 与 employee 分开）
HR 在"薪资管理"按员工+月份录入——选择员工后自动带出当月绩效等级与建议绩效奖金（可修改），实发自动计算；员工在"我的薪资"查看本人记录。

### 4.10 用户管理（admin）
创建账号并关联员工档案，可修改角色/重置密码。注意：删除员工前需先解除账号关联。

## 5. 数据重置

演示数据被操作污染后，随时可恢复出厂状态：

```bash
cd backend
python -m app.seed
```

（会清空数据库并重建全部演示数据，后端无需重启）

## 6. 常见问题

| 问题 | 解决 |
| --- | --- |
| 前端页面接口报 401 | 重新登录（Token 12 小时过期） |
| 打卡提示"未关联员工档案" | 该账号未关联员工，用 admin 在用户管理中关联 |
| 导入 Excel 失败 | 检查表头是否为：工号/姓名/性别/手机号/邮箱/部门/职位/入职日期/状态，部门职位必须已存在 |
| 端口被占用 | 后端改 `--port 8001`，前端 `vite.config.js` 改端口并同步代理 target |

## 7. 云端部署（可选加分项，CloudStudio）

1. 把本项目推送到 GitHub 公开仓库
2. 注册 cloudstudio.net（新用户赠 50 机时，4核8G），个人中心 → 创建应用 → 从 Git 仓库导入
3. 环境初始化后打开终端，执行 `sh start.sh`
4. 平台自动识别 3000 端口生成公网 HTTPS 链接，打开即可访问
5. 如需重置数据：终端执行 `cd backend && python seed.py`

> 说明：项目已内置 CloudStudio 适配（start.sh、Vite 0.0.0.0 监听、/api 代理、相对路径请求基址），导入即可用，无需改任何代码。
