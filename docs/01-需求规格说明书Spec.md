# 企业员工管理系统 — 功能需求规格说明书（Spec）

| 项目名称 | 企业员工管理系统 |
| --- | --- |
| 文档版本 | V2.0（含审批工作流/消息通知/绩效/公告扩展） |
| 编写日期 | 2026-08-24 |
| 技术栈 | Vue3 + FastAPI + SQLite |

## 1. 项目背景与目标

某中小企业需要一套员工信息管理系统，用于管理员工档案、部门架构、职位体系、日常考勤（含打卡）、请假审批、薪资核算以及数据可视化仪表板等核心人事业务。系统旨在提升 HR 管理效率、规范员工行为记录，并为管理层提供数据决策支持。

## 2. 用户角色与权限

| 角色 | 说明 | 主要权限 |
| --- | --- | --- |
| admin（系统管理员） | 系统级管理 | 用户管理（创建/修改/删除账号、关联员工、角色分配、重置密码） |
| hr（HR） | 人事业务操作者 | 部门/职位/员工管理、考勤规则、月度考勤、请假记录、薪资录入、数据看板、智能提醒 |
| manager（部门主管） | 部门业务管理者 | 审批本部门员工的请假申请、查看本人考勤/薪资/请假 |
| employee（普通员工） | 一般员工 | 上下班打卡、提交请假、查看本人考勤/薪资/请假记录 |

## 3. 功能需求

### 3.1 认证与账号
- 用户通过用户名 + 密码登录，系统签发 JWT Token（有效期 12 小时）
- 支持修改本人密码
- 前端根据角色动态渲染菜单，后端对每个接口做角色鉴权

### 3.2 部门管理（hr）
- 部门列表（含部门内人员统计）
- 新增 / 编辑 / 删除部门（名称唯一；部门下存在员工或职位时禁止删除）

### 3.3 职位管理（hr）
- 职位列表（职位名称、所属部门、职级：初级/中级/高级/资深）
- 新增 / 编辑 / 删除职位（职位下存在员工时禁止删除）

### 3.4 员工管理（hr）
- 员工信息增删改查（姓名、工号、性别、手机号、邮箱、部门、职位、入职日期、在职状态）
- 支持按姓名/工号关键词、部门、状态组合筛选 + 分页
- **Excel 批量导入**：上传 .xlsx 文件按模板逐行创建，逐行校验（工号重复、部门/职位不存在等），返回成功/失败明细
- **Excel 导出**：按当前筛选条件导出全部员工

### 3.5 考勤管理
- **打卡（employee/manager）**：上班打卡、下班打卡；依据考勤规则自动判定状态
- **考勤规则配置（hr）**：上班时间、下班时间、迟到容忍分钟数
- **月度考勤统计（hr）**：按员工统计应出勤天数、实际出勤、迟到/早退/缺卡次数、请假天数、出勤率，支持按部门筛选
- 考勤状态判定规则：
  - 上班打卡时间 > 上班时间 + 容忍分钟 → 迟到
  - 下班打卡时间 < 下班时间 → 早退
  - 只打上班卡未打下班卡 → 缺卡
  - 其余 → 正常

### 3.6 审批工作流（请假/加班/报销/出差）【扩展】
- **发起申请（employee/manager）**：4 类申请——请假（事假/病假/年假/调休/婚假）、加班、报销（金额）、出差，统一标题+事由+（起止日期/天数），请假自动检查同时间段待审批冲突
- **审批（manager 本部门 / hr）**：通过或驳回，可填写审批意见；经理仅可审批本部门
- **记录查询**：员工看本人申请；HR 按类型/状态/部门筛选全部记录
- **设计要点**：通用审批表（request_type 字段），新增审批类型无需改表改代码 → 可迭代拓展

### 3.7 消息通知中心【扩展】
- 顶栏铃铛 + 未读红点（前端 30 秒轮询）
- 通知类型：待办（新申请提交时通知审批人）、审批结果（通过/驳回实时通知申请人）、公告（发布后全员通知）
- 支持单条已读、全部已读、消息中心全量列表
- 设计要点：审批结果"申请后石沉大海"痛点闭环，符合成熟企业系统体验

### 3.8 绩效管理【扩展】
- **绩效评分（manager 本部门 / hr）**：月度评分 0-100，自动映射等级 S/A/B/C（≥90/≥80/≥70/<70），绩效系数 1.5/1.2/1.0/0.6
- **绩效-薪资联动**：薪资录入时自动带出建议绩效奖金（= 系数 × 基本工资 × 20%，可修改）
- **查询**：员工查看本人绩效（最新 + 历史）；HR/主管按月份/部门管理
- 规则：每人每月一条（唯一约束），主管跨部门评分被拒

### 3.9 公告中心【扩展】
- HR 发布、编辑、删除公告；发布后自动通知全体员工
- 全员按时间线查看；员工工作台展示最新 3 条

### 3.10 数据可视化看板（hr）
- 统计卡片（渐变样式）：在职员工总数、本月入职、累计离职、本月出勤率（对比上月）
- 图表：部门人数分布（饼图）、职级比例（饼图）、本月请假统计（柱状图）、薪资总额趋势（近 6 个月折线图）

### 3.11 智能考勤异常提醒（hr）【创新功能】
基于规则引擎自动检测并展示异常：
- 本月连续 3 天及以上迟到（严重提醒）
- 本月缺卡 ≥ 3 次
- 年度请假超额度（年假 5 天、事假 10 天）
- 部门当月出勤率低于 90%
目的：用自动化替代 HR 人工翻查考勤，提升管理效率。

### 3.12 员工工作台（employee/manager）
- 个人档案信息、今日考勤状态
- 本月考勤统计、本月请假天数、最近薪资
- 最新公告（3 条）+ 快捷入口：打卡、申请、薪资

## 4. 非功能需求

| 项 | 要求 |
| --- | --- |
| 性能 | 单机承载百人级规模，接口响应 < 1s |
| 安全 | 密码 PBKDF2 加盐哈希存储；JWT 鉴权；接口级角色权限校验；SQLAlchemy 参数化查询防 SQL 注入 |
| 易用性 | 全中文界面，Element Plus 组件库，操作路径 2-3 步内完成 |
| 部署 | 前后端可分别本地部署；兼容 CloudStudio 云端沙箱一键启动（start.sh） |
| 数据 | SQLite 文件数据库，提供 seed.py 一键生成演示数据 |
